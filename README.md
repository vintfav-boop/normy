# Нормы ЖАТ — веб-приложение (PWA)

Это PWA-упаковка исходного веб-приложения из предоставленного APK. Интерфейс и бизнес-логика оставлены в исходном `index.html`; добавлены манифест, иконки и service worker для установки на экран «Домой» и офлайн-загрузки оболочки.

## Публикация

Разместите ВСЁ содержимое этой папки на HTTPS-хостинге (например, GitHub Pages, Netlify или Cloudflare Pages). Не открывайте `index.html` как локальный файл: для PWA нужен HTTPS (или localhost).

## Установка на iPhone

1. Откройте опубликованный HTTPS-адрес в Safari.
2. Нажмите «Поделиться» → «На экран Домой».
3. При желании включите «Открывать как веб-приложение» (если этот переключатель доступен).
4. Запустите приложение с нового значка.

## Данные и ограничения

- Данные приложения хранятся в `localStorage` браузера на устройстве. Очистка данных Safari/сайта может удалить их. Регулярно используйте «Создать копию сейчас» и храните JSON-файл в приложении «Файлы» или iCloud Drive.
- Автоматический выбор папки резервного копирования через `showDirectoryPicker` на iPhone Safari не поддерживается; ручной экспорт/восстановление остаётся основным способом.
- Импорт/экспорт XLSX использует локальную копию SheetJS. Выбор файлов выполняется через стандартный интерфейс iOS.
- Системная отправка отчётов зависит от возможностей Safari/iOS.
- Service worker кэширует оболочку и библиотеку Excel; внешние ресурсы не обязательны для основной работы.
- Установка PWA не требует публикации в App Store и не требует Apple Developer Program.

## Проверка

Проверьте после размещения: добавление позиции, закрытие смены, месячный отчёт, импорт/экспорт базы, ручной JSON-бэкап и восстановление.
